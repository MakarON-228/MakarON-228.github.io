# Команды терминала

Терминал-пасхалка сайта (SPEC.md §7.11). Код — эта папка, подписи и описания команд — `ui.terminal` в
`src/data/resume.ts`, весь выводимый текст берётся оттуда же. Список ниже сверяет с кодом тест
`commands.test.ts`: новая команда или имя без строки здесь — красный тест.

## Как открыть и закрыть

| Клавиша / действие | Что делает |
|---|---|
| `` ` `` | открыть терминал (на русской раскладке — та же клавиша, «ё»; в полях ввода не срабатывает) |
| кнопка `›_` в навигации | открыть терминал |
| `Esc`, `×`, клик по затемнению | закрыть |
| `exit` | закрыть командой |

## Команды

Регистр не важен: `HELP`, `Cat Skills` работают.

| Команда | Что делает |
|---|---|
| `help` | список команд с описаниями |
| `whoami` | имя, роль, summary, локация и языки |
| `ls` | дерево секций; в experience / hackathons / projects — id записей |
| `cat <name>` | печатает секцию или запись; можно несколько имён: `cat sibur score-editor` |
| `open <name>` | закрывает терминал и прокручивает страницу к секции или записи |
| `cv` | скачивает PDF с резюме |
| `contact` | email, Telegram и GitHub ссылками |
| `theme light\|dark` | переключает тему (кнопка темы в навигации тоже переключается); без аргумента — текущая тема |
| `clear` | очищает экран |
| `exit` | закрывает терминал |

Пасхалка, в `help` её нет:

| Команда | Что делает |
|---|---|
| `sudo hire makar` | «Access granted» — контакты и ссылка на CV |
| `sudo …` (всё остальное) | «guest is not in the sudoers file. This incident will be reported.» |

## Имена для `cat` и `open`

Как их показывает `ls`; косая черта в конце (`projects/`) допустима.

| Имя | Что это |
|---|---|
| `experience` | секция Experience |
| `tmh-internship` | стажировка в TMH |
| `hackathons` | секция Hackathons (с капсулой `3 entered · 3 won`) |
| `yandex` | Yandex Vibe Coding Hackathon |
| `tmh-hackathon` | TMH Hackathon |
| `young-scientists` | Young Scientists Hackathon |
| `projects` | секция Projects |
| `sibur` | Chemical Feedstock Selection System |
| `score-editor` | Score Editor |
| `education` | секция Education |
| `skills` | секция Skills |
| `contact` | секция Contact |

## Клавиши в строке ввода

| Клавиша | Что делает |
|---|---|
| `Enter` | выполнить команду |
| `Tab` | дополнить: команды, имена для `cat` / `open`, `light` / `dark` для `theme`, `hire makar` после `sudo`; несколько вариантов — дописывает общее начало, а если дописывать нечего, печатает список. На пустой строке `Tab` не перехватывается — фокус уходит к кнопке закрытия и ссылкам |
| `↑` / `↓` | история команд; недописанная строка сохраняется |
